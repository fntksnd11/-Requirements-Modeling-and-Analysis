# Lab 4: Модель бізнес-процесу (Activity Diagram)

```mermaid
flowchart TD
    Start((Початок)) --> U1["Користувач: Сформувати та надіслати запит"]
    U1 --> S1["Система: Прийняти й зареєструвати запит"]

    S1 --> Fork1{{"Fork: Запуск паралельних гілок"}}
    Fork1 --> P1["Система: Перевірити дані, права та умови"]
    Fork1 --> P2["Система: Підготувати та зарезервувати ресурс"]

    P1 --> Join1{{"Join: Очікування завершення обох гілок"}}
    P2 --> Join1

    Join1 --> Dec1{"Умови виконано та ресурс готовий?"}

    Dec1 -- "Ні" --> Roll1["Система: Зняти резерв (якщо створено)"]
    Roll1 --> U_Dec1["Користувач: Отримати повідомлення про відмову (declined)"]
    U_Dec1 --> End_Declined((Кінець: Відхилено))

    Dec1 -- "Так" --> SendMsg["Система -> Зовнішній учасник: Надіслати повідомлення-запит"]
    SendMsg --> ExtProc["Зовнішній учасник: Обробити отримане повідомлення"]
    SendMsg --> TimerWait["Система: Очікувати відповідь (активний таймер)"]

    ExtProc -- "Повідомлення: Підтверджено" --> MsgOk["Система: Отримано підтвердження"]
    ExtProc -- "Повідомлення: Відхилено" --> MsgDeclined["Система: Отримано відмову"]
    TimerWait -- "Таймаут: відповідь не надійшла" --> AltStart["Система: Перехід в альтернативну гілку (alt)"]

    MsgOk --> CommitMain["Система: Зафіксувати успішне виконання (main)"]
    CommitMain --> U_Main["Користувач: Отримати підтвердження та результат"]
    U_Main --> End_Main((Кінець: Успішно))

    MsgDeclined --> Roll2["Система: Відкотити резерв та зафіксувати відмову (declined)"]
    Roll2 --> U_Dec2["Користувач: Отримати причину відмови"]
    U_Dec2 --> End_Declined

    AltStart --> AltRetry{"Виконати повторну спробу?"}
    AltRetry -- "Так" --> SendMsg
    AltRetry -- "Ні (скасувати)" --> Roll3["Система: Безпечно зняти резерв та зафіксувати скасування (alt)"]
    Roll3 --> U_Alt["Користувач: Отримати статус скасування / очікування"]
    U_Alt --> EndAlt((Кінець: Альтернатива / Скасовано))
```
